# pva-1k-ukol1

Write a program that randomly picks a whole number between 1 and 100 and asks the user to guess it. After each guess, the program should tell the user whether the secret number is higher or lower. When the user guesses correctly, display a congratulations message along with the number of attempts it took.

Requirements:
- Generate a random number from 1 to 100.
- Handle invalid input (e.g., letters or numbers out of range) without crashing.
- Count and display the number of attempts.

Bonus: Offer the player the option to play again, or add difficulty levels with different number ranges.
